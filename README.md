
# Student Grade Manager 

## About the Project

Student Grade Manager is a simple Python application that helps users manage student records and track their academic performance. It runs in the terminal and stores student data in a JSON file.

I built this project to improve my Python programming skills and learn how to develop a complete application.

## Features

- Add new students with their grades
- Display all registered students
- Search for students by name
- Calculate grade statistics
- Find the student with the highest score
- Validate user input
- Prevent duplicate student names
- Save and load student data using JSON
- Handle missing or invalid data files

## Technologies Used

- **Python** — application logic and data processing
- **JSON** — storing student records
- **Git and GitHub** — version control and project hosting
- **Visual Studio Code** — development environment
